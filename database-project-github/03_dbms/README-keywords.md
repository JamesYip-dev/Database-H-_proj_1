# 多关键词查询实验

运行 `./03_dbms/run-keywords.sh`；总入口 `run-comparison.sh` 也会先运行本实验，再运行姓名更新。

- 词表：`keywords.txt`，预先固定 40 个首字母大写的英文词，每个词的查询机会相同。它是包含匹配，不是完整单词或全文检索；不代表真实搜索频率。
- 输入：`data/movies.csv` 与两库 `public.movies`，计时前核对一致。每词逐次核对完整编号和标题，校验在计时外。
- SQL：`SELECT movieid,title FROM public.movies WHERE title LIKE '%Love%' ESCAPE '!'`；其他词替换 Love，特殊字符按字面量转义。
- 每组每词预热 10 次、正式 30 次，共三组；每轮词序随机，种子为 20261011+组号；同一词紧邻执行三种方法并轮换先后。不清缓存。
- CSV 每次打开、解析、筛选并收集结果；数据库包含 JDBC 请求和完整返回。不计连接、ANALYZE、核对及打印。
- 汇总为每组每方法所有正式单次查询的中位数。40 个词重复次数相同，每方法每组 1,200 次；不使用平均值。
- `results/keywords/<时间>/`：`keywords.csv` 保存词表及匹配数；`group-*.csv` 保存正式与预热计时、词序和方法顺序；`summary.csv` 保存中位数；`method.txt` 保存规则与种子。

旧的单词查询代码和结果仍供早期实验使用。当前报告以多关键词结果为准。配置与本机密码由公共启动脚本读取，不需要手动输入，也不要分享密码文件。
